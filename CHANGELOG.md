# Changelog

All notable changes to datafromzero are recorded here. The format follows
[Keep a Changelog](https://keepachangelog.com/en/1.1.0/), and the curriculum uses
[Semantic Versioning](https://semver.org/) as described in SPEC.md §9. Every bullet starts with a bold, dated summary in
plain words (SPEC D54); the site's "What's new" page shows only those summaries, and the detail after them stays here.
