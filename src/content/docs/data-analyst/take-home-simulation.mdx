## The question

A hiring manager sends you a take-home and a deadline. Two things get read: whether you can write the SQL, and whether you can be trusted with messy data. This lesson is both in 90 minutes, marked by a rubric you can read now.

There is no single right answer to Part B. Several ways of cleaning and several recommendations earn full marks; a choice you do not state earns none.

## Rubric

Eight items, each scored 2 (full), 1 (partial) or 0 (none): 16 in all. Items 1 to 3 mark Part A and items 4 to 8 mark Part B. The rubric grades the chain from data to recommendation: any cleaning choice or recommendation that your reasoning supports can score 16.

**1. Part A, results.**

- **Full:** at least 4 of the 5 queries return the reference result.
- **Partial:** 2 or 3.
- **None:** 0 or 1.

**2. Part A, method.**

- **Full:** in at least 4 of the 5 queries a comment says what one row is, and across the five you used a join of three or more tables, an aggregate, a named CTE and a conditional filter.
- **Partial:** 2 or 3 comments, or one of the four missing.
- **None:** otherwise.

**3. Part A, time.**

- **Full:** all five attempted by 30:00.
- **Partial:** 3 or 4.
- **None:** fewer than 3.

**4. Part B, scope note.**

- **Full:** all four parts (question, minutes adding to 55 or less, two things left out, one assumption), written before the data log.
- **Partial:** two or three parts.
- **None:** one part or none, or written after the work.

**5. Part B, data log.**

- **Full:** at least 4 distinct problems, each with rows or dollars counted and an action.
- **Partial:** 2 or 3 problems, or problems with no counts.
- **None:** 0 or 1.

**6. Part B, reconciliation.**

- **Full:** the cleaned total is compared with a second source, the rows are counted after every step that removes rows, and every dollar of difference has a name, so that nothing is left unexplained.
- **Partial:** compared, but part of the gap has no name, or the row counts are missing.
- **None:** no second source.

**7. Part B, answer page.**

- **Full:** the answer in the first sentence; three numbers, each with unit, period and rule (which rows, which dollars, how you treated any entry you doubted); at least one hedge tied to a number; at most 250 words.
- **Partial:** two of those four.
- **None:** one of the four or none.

**8. Part B, recommendation.**

- **Full:** one action, one reason tied to a number, one risk and one next check.
- **Partial:** two or three of the four.
- **None:** one or none, or an action the numbers do not support.

A total of 13 or more is ready to send. From 8 to 12, redo the items that scored 0 or 1. Below 8, redo the cleaning before you redo the writing.

### Part A: results and queries

Each query below starts with its grain in a comment. The results are for June 1 to 30.

```sql
-- 1. one row is a store
SELECT s.store_name AS store,
       SUM(oi.quantity * p.unit_price_usd - oi.discount_usd) FILTER (WHERE c.city = s.city) AS local_sales,
       SUM(oi.quantity * p.unit_price_usd - oi.discount_usd) FILTER (WHERE c.city <> s.city) AS other_sales,
       ROUND(100 * SUM(oi.quantity * p.unit_price_usd - oi.discount_usd) FILTER (WHERE c.city = s.city)
             / SUM(oi.quantity * p.unit_price_usd - oi.discount_usd), 1) AS local_pct
FROM orders o
JOIN order_items oi ON oi.order_id = o.order_id
JOIN products p ON p.product_id = oi.product_id
JOIN customers c ON c.customer_id = o.customer_id
JOIN stores s ON s.store_id = o.store_id
WHERE o.status = 'completed'
  AND o.ordered_at >= DATE '2026-06-01' AND o.ordered_at < DATE '2026-07-01'
GROUP BY s.store_name
ORDER BY s.store_name;
```

|---|---:|---:|---:|
| Campus | \$1,451.25 | \$139.50 | 91.2% |

```sql
-- 2. one row is a customer (first CTE), then a group of customers
WITH per_customer AS (
  SELECT o.customer_id, COUNT(DISTINCT o.order_id) AS orders,
         SUM(oi.quantity * p.unit_price_usd - oi.discount_usd) AS net_sales
  FROM orders o
  JOIN order_items oi ON oi.order_id = o.order_id
  JOIN products p ON p.product_id = oi.product_id
  WHERE o.status = 'completed' AND o.customer_id IS NOT NULL
    AND o.ordered_at >= DATE '2026-06-01' AND o.ordered_at < DATE '2026-07-01'
  GROUP BY o.customer_id
)
SELECT CASE WHEN orders >= 3 THEN '3 or more' ELSE CAST(orders AS VARCHAR) END AS june_orders,
       COUNT(*) AS customers, SUM(net_sales) AS net_sales
FROM per_customer
GROUP BY 1
ORDER BY 1;
```

| June orders | customers | net sales |
|---|---:|---:|
| 1 | 37 | \$462.50 |
| 2 | 38 | \$931.00 |
| 3 or more | 59 | \$3,086.50 |

```sql
-- 3. one row is an order (CTE), then a store
WITH order_totals AS (
  SELECT o.order_id, s.store_name AS store, o.payment_method, COUNT(*) AS line_count,
         SUM(oi.quantity * p.unit_price_usd - oi.discount_usd) AS total
  FROM orders o
  JOIN order_items oi ON oi.order_id = o.order_id
  JOIN products p ON p.product_id = oi.product_id
  JOIN stores s ON s.store_id = o.store_id
  WHERE o.status = 'completed'
    AND o.ordered_at >= DATE '2026-06-01' AND o.ordered_at < DATE '2026-07-01'
  GROUP BY o.order_id, s.store_name, o.payment_method
)
SELECT store, COUNT(*) AS orders,
       COUNT(*) FILTER (WHERE (payment_method = 'cash' AND total >= 15)
                           OR (payment_method = 'mobile' AND line_count >= 3)) AS flagged
FROM order_totals
GROUP BY store
ORDER BY store;
```

|---|---:|---:|
| Campus | 125 | 10 |
| Harbor | 111 | 12 |
| Old Town | 117 | 9 |

```sql
-- 4. one row is a product at a store (first CTE), then a store (second CTE)
WITH product_sales AS (
  SELECT s.store_name AS store, p.product_name AS product,
         SUM(oi.quantity * p.unit_price_usd - oi.discount_usd) AS net_sales
  FROM orders o
  JOIN order_items oi ON oi.order_id = o.order_id
  JOIN products p ON p.product_id = oi.product_id
  JOIN stores s ON s.store_id = o.store_id
  WHERE o.status = 'completed'
    AND o.ordered_at >= DATE '2026-06-01' AND o.ordered_at < DATE '2026-07-01'
  GROUP BY s.store_name, p.product_name
),
store_sales AS (
  SELECT store, SUM(net_sales) AS store_total FROM product_sales GROUP BY store
)
SELECT ps.store, ps.product, ps.net_sales, ROUND(100 * ps.net_sales / ss.store_total, 1) AS share_pct
FROM product_sales ps
JOIN store_sales ss ON ss.store = ps.store
WHERE ps.net_sales > 0.12 * ss.store_total
ORDER BY ps.store;
```

| store | product | net sales | share |
|---|---|---:|---:|
| Harbor | Avocado Toast | \$212.00 | 14.5% |
| Old Town | Latte | \$228.00 | 16.0% |

```sql
-- 5. one row is an order (first CTE), then a store (second CTE)
WITH order_totals AS (
  SELECT o.order_id, o.store_id, SUM(oi.quantity * p.unit_price_usd - oi.discount_usd) AS total
  FROM orders o
  JOIN order_items oi ON oi.order_id = o.order_id
  JOIN products p ON p.product_id = oi.product_id
  WHERE o.status = 'completed'
    AND o.ordered_at >= DATE '2026-06-01' AND o.ordered_at < DATE '2026-07-01'
  GROUP BY o.order_id, o.store_id
),
store_avg AS (
  SELECT store_id, AVG(total) AS avg_total FROM order_totals GROUP BY store_id
)
SELECT s.store_name AS store, COUNT(*) AS orders,
       COUNT(*) FILTER (WHERE t.total > a.avg_total) AS above_average
FROM order_totals t
JOIN store_avg a ON a.store_id = t.store_id
JOIN stores s ON s.store_id = t.store_id
GROUP BY s.store_name
ORDER BY s.store_name;
```

|---|---:|---:|

```sql
CREATE OR REPLACE VIEW export_raw AS SELECT * FROM read_csv('take_home_export.csv');

CREATE OR REPLACE VIEW export_clean AS
SELECT line_id, order_id,
       COALESCE(TRY_STRPTIME(ordered_at, '%Y-%m-%d %H:%M:%S'),
                TRY_STRPTIME(ordered_at, '%m/%d/%Y %-I:%M %p')) AS ordered_at,
       store_code, product, category,
       CASE WHEN line_id = 6952 THEN 2 ELSE quantity END AS quantity,
       CAST(unit_price AS DECIMAL(10, 2)) AS unit_price, CAST(discount AS DECIMAL(10, 2)) AS discount
FROM export_raw
WHERE product <> 'TOTAL'
QUALIFY ROW_NUMBER() OVER (PARTITION BY order_id, product, quantity, discount ORDER BY line_id) = 1;

SELECT 'file as read' AS step, COUNT(*) AS rows, ROUND(SUM(line_total), 2) AS dollars FROM export_raw
UNION ALL SELECT 'cleaned, 2075 as 2 units', COUNT(*), ROUND(SUM(quantity * unit_price - discount), 2) FROM export_clean
UNION ALL SELECT 'cleaned, minus refunds', COUNT(*) FILTER (WHERE quantity > 0),
       ROUND(SUM(quantity * unit_price - discount) FILTER (WHERE quantity > 0), 2) FROM export_clean;
```

DuckDB's `read_csv` reads `ordered_at` as text, because of the two formats. `TRY_STRPTIME` returns `NULL` where a format does not fit, so `COALESCE` tries the second format on the rows the first one missed; `%-I` is the 12-hour clock without a leading zero, and `QUALIFY` filters on the window function. The three result rows are 2,007 and 28,052.50; 1,991 and 13,759.25; 1,979 and 13,807.50.
