## The question

The team asks the data scientist two things this week: *can we use an assistant to build the churn model, and can a language model read the cancellation notes for us?* Both come back with a confident answer. Four notes of the 60 that the lesson works with (written for it) and the label that the writer meant:

| note | label |
|---|---|
| At $7.99 a month it costs more than the savings it finds me. | too_expensive |
| I haven't added an expense in a month. | not_using |
| It can't import my bank statement. | missing_feature |
| Switched to another budgeting app that my bank offers. | found_alternative |

By the end you can grade both with the metrics you already know, put a dollar figure on them and say when to train a model instead.

### 1. Grade the assistant's answers

**Idea.** Treat each answer as a claim and run the checks of C38 that fit: predict the number before you look, recompute it a second way, then decide. For modeling the second way is a rerun on held-out people, and for a claim about what to do it is a question about what the data can show. Log every verdict with one sentence.

<Aside type="note" title="Four answers written for this lesson, in the style of an assistant">

**A. The split.** I cut the people into 13,362 to fit and 4,454 to test, stratified, seed 2026; both parts have 54.4 percent churners.

**B. The score.** The logistic regression on the week-1 columns has a ROC AUC of 0.62 on the test people: `roc_auc_score(y_test, model.predict(X_test))`.

**C. A tree.** An unlimited decision tree scores 0.791 accuracy: `deep.score(Xe_train, y_train)`.

**D. The decision.** Paid-social people churn 3.2 times as often, so stopping paid social would cut churn by two thirds.

</Aside>

**Try it:** check each answer, then write the log.

```python
prep = ColumnTransformer([("cat", OneHotEncoder(handle_unknown="ignore"), STATIC), ("num", "passthrough", WEEK1)])
Xe_train, Xe_test = prep.fit_transform(X_train), prep.transform(X_test)
deep = DecisionTreeClassifier(random_state=SEED).fit(Xe_train, y_train)                  # the assistant's tree, with no limit on its depth
paid = table["channel"] == "paid_social"
a = (len(X_train), len(X_test), round(float(y_train.mean()), 3), round(float(y_test.mean()), 3))                          # answer A: the split
b = (round(float(roc_auc_score(y_test, model.predict(X_test))), 3), round(float(roc_auc_score(y_test, model.predict_proba(X_test)[:, 1])), 3))      # answer B: hard labels, then chances
c = (round(float(deep.score(Xe_train, y_train)), 3), round(float(deep.score(Xe_test, y_test)), 3))                          # answer C: training rows, then test rows
d = (round(float(table.loc[paid, "churned"].mean()), 3), round(float(table.loc[~paid, "churned"].mean()), 3), round(float(table["churned"].mean()), 3))      # answer D
log = pd.DataFrame([
    ("A split", f"counted {a[0]:,} and {a[1]:,}; churners {a[2]} and {a[3]}", "accept", "The counts and the shares match the claim."),
    ("B ROC AUC", f"with chances {b[1]}, with hard labels {b[0]}", "revise", "ROC AUC needs the chances: predict_proba."),
    ("C tree", f"training rows {c[0]}, test rows {c[1]}", "revise", "The score was read on the rows the tree learned from."),
    ("D cut paid social", f"churn {d[0]} for paid social, {d[1]} for the rest, {d[2]} for all", "reject", "A gap between groups is not what a change would do."),
], columns=["answer", "check", "verdict", "reason"])
print(log.to_string(index=False))
```

**Predict:** Four answers came back from an assistant, each with a claim. Which do you accept, which do you revise, and do you reject any?

*Why:* A is accepted: both counts and both shares match. B is revised: the claim is a ROC AUC of 0.62, but a ROC AUC takes the chances, and the call gave it hard 0/1 labels (0.623); with `predict_proba` it is 0.690, the number of DS2. C is revised: 0.791 is the score on the rows the tree learned from. On the 4,454 test people it is 0.582, 3.8 points above the flat guess of 0.544. D is rejected: paid-social people churn at 0.788 against 0.474 for the rest, a ratio of 1.7, not 3.2 (an odds ratio multiplies odds, not chances), and removing them from a table changes who is in it, not whether anyone stays. No experiment in the data supports "would cut churn", so the claim cannot be checked here. Reject when the approach is wrong or you cannot check it.

### 2. Grade a classifier against labels

**Idea.** A classifier of text is graded like any other: put its answers beside labels you trust. An answer outside the allowed labels is an error, not a missing value. Read a confusion matrix, whose rows are the true labels and whose columns are the predicted ones, then recall (the share of each true label found) and precision (the share of each predicted label that was right), and an interval for the accuracy, because 60 notes are few.

**Try it:** the answers of run 1 against the 60 labels.

```python
valid = notes["run1"].isin(LABELS)
pred = notes["run1"].where(valid, "invalid")                                      # an answer outside the five labels counts as wrong
hit = (pred == notes["truth"]).to_numpy()
print(int((~valid).sum()), round(float(hit.mean()), 3), round(float(notes["truth"].value_counts(normalize=True).max()), 3))
print(pd.crosstab(notes["truth"], pred).reindex(index=LABELS, columns=LABELS + ["invalid"], fill_value=0).to_string())
recall = pd.Series({k: float(hit[(notes["truth"] == k).to_numpy()].mean()) for k in LABELS})
precision = pd.Series({k: float(hit[(pred == k).to_numpy()].mean()) for k in LABELS})
print(pd.DataFrame({"recall": recall.round(2), "precision": precision.round(2)}).T.to_string())
rng = np.random.default_rng(SEED)
accs = [hit[rng.integers(0, len(hit), len(hit))].mean() for _ in range(2000)]      # resample the 60 notes
print(np.round(np.percentile(accs, [2.5, 97.5]), 3))
```

**Predict:** Run 1 labels 60 notes. About how many of its answers are right: about 0.55, about 0.85 or about 0.98? And how many are not one of the five labels?

### 3. Two runs, and what a pass costs

**Idea.** If a model samples its answers, two runs of one prompt can differ, so run twice and count the notes that changed. A *token* is the unit a model is billed in. Count it as about 4 characters of English, the rule of thumb of the OpenAI help page, and price it with the vendor's page, with a date, because prices move. Cost is a line of arithmetic: tokens for each note, times notes, times the price per million.

**Try it:** the agreement of the two runs, the tokens and the dollars of one assistant run at its floor and of a pass over every cancellation, and the cost of a million notes.

```python
agree = float((notes["run1"] == notes["run2"]).mean())
print(round(agree, 3), int((notes["run1"] != notes["run2"]).sum()))
PROMPT = "Classify this cancellation note as one of: too_expensive, not_using, missing_feature, found_alternative, other. Answer with the label only.\nNote: "
PRICE = {"Haiku 5.5": (0.10, 0.50), "Sonnet 5.5": (2.00, 10.00)}               # US dollars per million input and output tokens, from the vendor's pricing page of 2026-11-24
CHARS_PER_TOKEN = 4                                                              # a rule of thumb for English text, not the count of any tokenizer
tokens_in = (len(PROMPT) + notes["text"].str.len()) / CHARS_PER_TOKEN
tokens_out = notes["run1"].str.len() / CHARS_PER_TOKEN
per_note = (float(tokens_in.mean()), float(tokens_out.mean()))
print(round(per_note[0], 1), round(per_note[1], 1))
ANSWERS = ["A. The split: 13,362 to fit, 4,454 to test, 54.4% churners in both parts.", "B. The logistic regression has a ROC AUC of 0.62 on the test people.",
           "C. An unlimited decision tree scores 0.791 accuracy.", "D. Paid-social people churn 3.2 times as often, so stopping paid social would cut churn by two thirds."]
context = MODELING_SQL + table.head(5).to_csv()                                  # what the assistant was given: the table's definition and five rows
run_in, run_out = len(context) / CHARS_PER_TOKEN, len(" ".join(ANSWERS)) / CHARS_PER_TOKEN
print(round(run_in), round(run_out), f"{(run_in * PRICE['Sonnet 5.5'][0] + run_out * PRICE['Sonnet 5.5'][1]) / 1e6:.4f}")      # the floor of one run: no code, no retries
for model_name, (p_in, p_out) in PRICE.items():
    cost = (per_note[0] * p_in + per_note[1] * p_out) / 1e6                       # dollars for one note
    print(model_name, f"{cost * CANCELERS:.4f}", f"{cost * 1_000_000:,.2f}")       # all 692 cancellations, and a million notes
```

**Predict:** Classifying all 692 cancellations with the small model: will the bill be under a cent, about a dollar, or about a hundred dollars?

### 4. Or a model you train

**Idea.** A text classifier you train needs labeled rows; a language model needs none to start. Ask what the trained one would need to reach the bar. Score it as before, by cross-validation on the labeled notes, with the mean and the range of the folds, and look at how the score moves when it trains on more notes.

**Try it:** a TF-IDF logistic regression trained on 40, 48 and 50 of the 60 notes, with the mean and range of its folds.

```python
text_model = make_pipeline(TfidfVectorizer(ngram_range=(1, 2)), LogisticRegression(max_iter=1000))
for folds in (3, 5, 6):
    scores = cross_val_score(text_model, notes["text"], notes["truth"], cv=StratifiedKFold(folds, shuffle=True, random_state=SEED))
    print(folds, round(60 - 60 / folds), round(float(scores.mean()), 3), round(float(scores.min()), 3), round(float(scores.max()), 3))
```

**Predict:** With 60 labeled notes, will a classical text model trained on 48 of them score about 0.95, about 0.80 or under 0.6 on the other 12?

<details>
<summary>Reveal the result</summary>

```text
3 40 0.433 0.4 0.45
5 48 0.433 0.333 0.583
6 50 0.4 0.3 0.6
```

</details>

*Why:* Under 0.6: with 48 training notes the mean is 0.433, folds from 0.333 to 0.583, and with 40 or 50 notes it is 0.433 and 0.400. The trained model sits far below 0.833, the accuracy of the illustrated run, and does not improve between 40 and 50 notes: 60 labeled notes are not enough, and how many are cannot be read from here. Train your own when you have thousands of labeled rows, a fixed set of labels and a volume where a per-note fee adds up; use a language model when labels are few or change, and grade it the same way, against labels, with an interval, on a prompt written before you look at the score.

<Aside type="tip" title="Remember">

- An answer is a claim: predict it, recompute it a second way, then accept, revise or reject with one sentence.
- A score read on training rows, or an AUC fed hard labels, runs and is wrong.
- Grade a classifier against labels: invalid answers count as errors, read recall and precision by label, and put an interval on 60 notes.
- Cost is tokens times notes times a dated price; the tokens are an estimate until the API reports them.
- Train your own when labels are many and fixed; else grade the language model.

**Common trap:** leaving out the hard notes and reporting the rest. The accuracy rises and the notes a reader would disagree on disappear.

</Aside>

LONG_PROMPT_CHARS = 640                    # the same task with three worked examples in the prompt
tokens_in2 = (LONG_PROMPT_CHARS + notes["text"].str.len().mean()) / CHARS_PER_TOKEN
p_in, p_out = PRICE["Sonnet 5.5"]

**Spot the flaw.** A colleague grades run 1 on the 55 notes that give one reason and leaves out the 5 that give two, "because those are ambiguous anyway", and reports the accuracy of the starter. Put in `answer_3` the list [accuracy of run 1 on the 55 one-reason notes, accuracy of run 1 on the 5 two-reason notes], each rounded to 3 decimals. Expected: `answer_3` is a list of two numbers.

```python
easy = notes["hard"] == 0
colleague = round(float((notes.loc[easy, "run1"] == notes.loc[easy, "truth"]).mean()), 3)      # colleague: "the five two-reason notes are ambiguous anyway, so I left them out"
answer_3 = None  # replace None with [accuracy of run 1 on the 55 one-reason notes, accuracy of run 1 on the 5 two-reason notes], each rounded to 3 decimals
```

<details>
<summary>Hint</summary>

`notes["hard"]` is 1 for the two-reason notes. Take the mean of `run1 == truth` inside each group.

</details>

<details>
<summary>Half-solution</summary>

```python
easy = notes["hard"] == 0
answer_3 = [round(float((notes.loc[easy, "run1"] == notes.loc[easy, "truth"]).mean()), 3), ...]
```

</details>

<Solution>

```python
easy = notes["hard"] == 0
answer_3 = [round(float((notes.loc[easy, "run1"] == notes.loc[easy, "truth"]).mean()), 3), round(float((notes.loc[~easy, "run1"] == notes.loc[~easy, "truth"]).mean()), 3)]
```

Run 1 is right on 0.891 of the 55 one-reason notes and on 0.2 of the 5 two-reason notes: one right out of five. Leaving the hard notes out raised the accuracy from 0.833 to 0.891 and hid the notes where a real reader would also disagree. With 5 notes the 0.2 is itself very uncertain; the point is that the hard notes need their own line in the grade.

</Solution>
