## The question

The owner asks:

> How much is each order line worth after its discount, and what do all the lines add up to?

A line's amount is its quantity times the price of its product, minus its discount. Four lines of the `order_items` table, with the price of each product from the products table:

| order_item_id | product_name | quantity | unit_price_usd | discount_usd |
|---:|---|---:|---:|---:|
| 5191 | Espresso | 1 | 3.00 | 0.00 |
| 5192 | Mocha | 2 | 5.00 | 0.50 |
| 5193 | Cappuccino | 1 | 4.50 | 0.50 |
| 5194 | Chai Latte | 3 | 4.75 | 0.00 |

There are 3,287 lines, and a loop over each one is more than the question needs. By the end of this page one line of code gives the amount of every line, and a second one counts the lines of two units or more.

<Aside type="note" title="You already know this">

**Match.** In *Computed columns and data types* (S5), `quantity * unit_price_usd - discount_usd` made one new value for every row at once, with no loop. An array expression does the same: `quantity * price - discount` gives one amount for each line, and `sum()` adds them as `SUM` does, to the same 22,754.25 over all 3,287 lines, the canceled order and the extra-zero line included.

**Diverge.** In SQL a column has one type, and text is turned into a number with `CAST` (S5). An array has one type too; what it does when a list holds a value of another kind is the first thing unit 1 checks.

</Aside>

## Learn by doing

### 1. An array holds one type

**Idea.** NumPy is the library of arrays, and a pandas column behaves much like one; `np` is its usual short name. `np.array([...])` builds an array from a list. All the values of an array have the same type. `.shape` gives how many values it holds, and `.dtype` their type: `float64` is a decimal number and `int64` a whole number.

**Try it:**

```python
coffee = np.array([3.00, 3.50, 4.50, 4.50, 5.00, 4.75])  # the six coffee prices
print(coffee.shape, coffee.dtype)
print(np.array([3.25, 3.75, "n/a"]))
```

**Predict:** what shape and type does `coffee` have? What does the second array hold when one of its three values is text?

<details>
<summary>Reveal the result</summary>

```text
(6,) float64
['3.25' '3.75' 'n/a']
```

</details>

*Why:* `(6,)` is a shape of one dimension with six values, and all six are decimals, so the type is `float64`. In the second array the text `n/a` could not stay next to numbers, so every value became text. Nothing stopped and nothing warned: a spreadsheet range keeps each cell as it is, and an array has one type for all.

### 2. Math on a whole array

**Idea.** An operator works on a whole array at once, value by value, with no loop. With two arrays of the same length, `a * b` multiplies the first value by the first, the second by the second, and so on. With a plain number, as in `price * 2`, the number is stretched to the length of the array. That stretching is called broadcasting.

**Try it.** The first three lines are a Croissant (quantity 1, price 3.25), a Cold Brew (1, 4.75) and an Espresso (2, 3.00), none discounted:

```python
amount = quantity * price - discount
print(amount.shape, amount.sum())
print(amount[:3])
print(price[:3] * 2)
```

**Predict:** what are the three amounts of the first three lines? What is `price[:3] * 2`? The shape and the total are for you to read.

<details>
<summary>Reveal the result</summary>

```text
(3287,) 22754.25
[3.25 4.75 6.  ]
[6.5 9.5 6. ]
```

</details>

*Why:* one line gave one amount for each of the 3,287 lines, and `amount[:3]` shows the first three: 3.25, 4.75 and 2 times 3.00. The 3.25 and the 4.75 are the prices of the first two lines, times 1. In `price[:3] * 2` the single 2 was stretched over the three prices. The total, 22754.25, adds all 3,287 lines, the canceled order and the extra-zero line of order 2075 included. A loop over the same arrays, as in lesson P5, gives the same total in four lines:

```python
total = 0
for q, p, d in zip(quantity, price, discount):
    total = total + (q * p - d)
print(total)
```

```text
22754.25
```

### 3. A mask of True and False

**Idea.** A comparison on an array gives an array of `True` and `False`, one for each value. It is a mask. `True` counts as 1 and `False` as 0, so `mask.sum()` counts the `True` values. `array[mask]` keeps only the values where the mask is `True`.

**Try it.** Which lines have two units or more? The quantities of the first eight lines are 1, 1, 2, 1, 1, 2, 1, 2:

```python
multi = quantity >= 2
print(multi[:8])
print(multi.shape, multi.sum())
print(amount[multi].shape)
```

**Predict:** which of the first eight values of the mask are `True`? The shape and the count are for you to read.

<details>
<summary>Reveal the result</summary>

```text
[False False  True False False  True False  True]
(3287,) 1376
(1376,)
```

</details>

*Why:* the mask has one value for each line, so its shape matches `quantity`, and the `True` values sit where the quantity is 2 or more. `multi.sum()` counted them: 1,376 of the 3,287 lines. `amount[multi]` kept the amounts of those lines only, so its length is the same 1,376. Look at a mask and its shape before you use it; it is the same check that *Conditional totals with SUMIFS and COUNTIFS* (E7) did with a helper column of `TRUE` and `FALSE`.

### 4. np.where, an IF for every value

**Idea.** `np.where(condition, a, b)` goes through the array and takes `a` where the condition is `True` and `b` where it is `False`. It is the `IF` of *Decisions with IF, AND and OR* (E6) and the `CASE` of *Labels and buckets with CASE* (S6), done for every value at once.

**Try it.** A coupon takes 1.00 off every line of 6 dollars or more:

```python
after_coupon = np.where(amount >= 6, amount - 1, amount)
print(after_coupon[:8])
print(after_coupon.sum())
```

**Predict:** the first eight amounts are 3.25, 4.75, 6.00, 3.25, 9.25, 9.50, 3.00 and 6.50. Which become smaller, and what are they after the coupon? The total is for you to read.

<details>
<summary>Reveal the result</summary>

```text
[3.25 4.75 5.   3.25 8.25 8.5  3.   5.5 ]
21238.25
```

</details>

*Why:* the lines of 6.00, 9.25, 9.50 and 6.50 got the coupon, and the other four kept their amounts. An `if` statement decides about one value at a time, so it needs a loop; `np.where` decides for all 3,287 values at once. The total fell from 22754.25 to 21238.25, which is 1,516 coupons of 1.00.

### 5. Check: shape and type

Write down the three types, then run the cell. The arrays are those of the setup cell and of unit 3.

```python
print(quantity.dtype, price.dtype, multi.dtype)
```

<details>
<summary>Reveal the result</summary>

```text
int64 float64 bool
```

</details>

*Why:* quantities are whole numbers, prices are decimals, and a mask holds only `True` and `False`, which NumPy calls `bool`. Each array has one type.

<Aside type="tip" title="Remember">

- An array holds values of one type; `.shape` and `.dtype` describe it.
- An expression on arrays works on every value at once, with no loop; a plain number is stretched over the array.
- A comparison gives a mask; `mask.sum()` counts the `True` values and `array[mask]` keeps them.
- `np.where(condition, a, b)` is an IF for every value.
- Print a mask and its shape before you trust a filter.

**Common trap:** a Python list where you meant an array: `*` and `+` mean something else on a list, and nothing stops you.

</Aside>
