## The question

The owner asks:

> How much of the money comes from coffee, and how do the cafes compare month by month?

The sales of each store and month, the first rows of the table behind the grouped chart:

| store | month | amount |
|---|---:|---:|
| Old Town | 1 | 1,591.00 |
| Old Town | 2 | 1,162.00 |
| Campus | 1 | 1,518.75 |
| Campus | 2 | 1,508.25 |

By the end of this page you will draw the category totals and this table as grouped bars, and see what seaborn does with the rows you give it.

<Aside type="note" title="You already know this">

**Match.** In *Summarize with a PivotTable* (E15) you put the category in Rows and the amount in Values, and each category got one number. `sns.barplot` also names a category column and an amount column, and draws one bar for each category.

**Diverge.** pandas' `plot.bar()` draws the numbers it is given and summarizes nothing. `sns.barplot` on raw rows picks a summary for you, and unit 1 shows which.

</Aside>

### 1. seaborn on an Axes, and what barplot does with rows

**Idea.** `sns.barplot(data=table, x="column", y="column", saturation=1, ax=ax)` draws bars on a matplotlib Axes and returns that Axes. Titles, labels and `savefig` stay matplotlib's, as the seaborn page says it draws with matplotlib behind the scenes.

**Try it.** The category totals, drawn by seaborn:

```python
fig, ax = plt.subplots()
# saturation=1 keeps the colors as given (seaborn mutes them a little by default)
back = sns.barplot(data=by_category, x="category", y="amount", saturation=1, ax=ax)
print(type(back).__name__, back is ax)
print([round(float(p.get_height()), 2) for p in ax.patches])
```

**Predict:** what type will `sns.barplot` return, is it the same object as `ax`, and what will the four bar heights be?

```python
fig, ax = plt.subplots()
sns.barplot(data=sales, x="category", y="amount", seed=1, saturation=1, ax=ax)  # seed: the same random draw for the error bars every time
print([round(float(p.get_height()), 2) for p in ax.patches], len(ax.lines))
```

*Why:* `True`: a table of totals is drawn as those totals, with either library. They differ in what they do to rows you did not summarize.

<Aside type="tip" title="Remember">

- seaborn draws on a matplotlib Axes: `ax=ax` in, the same Axes out.
- `sns.barplot` on raw rows summarizes them, by default with the mean and an error bar. Give it totals if you want totals.
- `hue="column"` splits the bars by the values of a column. A missing row is a gap, not a 0.
- `sns.histplot(numbers, bins=n)` counts rows into bins, so the bars add up to the number of rows.
- `set_theme` changes the look of the charts after it, never their numbers.

**Common trap:** `sns.barplot` on raw rows draws averages, so the bars look like totals and are not.

</Aside>
