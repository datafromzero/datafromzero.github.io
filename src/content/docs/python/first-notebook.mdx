**Where do you write Python?** Almost anywhere.

You can save a plain text file that ends in `.py` and ask Python to run it. You can write that file in an editor such as VS Code. You can open a notebook on your own computer. Or you can open a notebook that lives on someone else's computer and use it from your browser.

This course starts with the notebook, because you already know the feeling. On the SQL pages you typed a query, pressed Run and read the result in the output box. In Excel you type in a cell and the answer shows up there. A notebook is that same feeling for code: a page where you type, press Run and see the answer under what you typed.

The idea comes from the lab. Scientists keep notebooks: what they tried, what happened and why, all on one page. Programmers borrowed it. The computer scientist Donald Knuth popularized writing plain-English explanation and code together, an idea called literate programming. Scientists and engineers often have to run a calculation and explain it to someone else, so notebooks that mix code, text and charts became a popular way to share their work.

Python got a better place to type in 2001. A graduate student, Fernando Pérez, started IPython because he wanted a better prompt and easy access to earlier output. In 2014 the project grew into Project Jupyter, which builds tools for interactive computing, notebooks included, for many languages. Today Jupyter works with over 40 programming languages, including Python, R and Julia.

Then the notebook moved into the browser. Google Colab, short for Colaboratory, is a hosted Jupyter notebook service. Hosted means someone else runs the computer: your code runs on a virtual machine that is private to your account, and your notebook is saved in your Google Drive. Colab needs no setup and is free of charge to use. Its free resources are not guaranteed and its limits change, so this course never depends on a number from it.
