## The question

The owner asks:

> Write one line for each cafe that says how many orders it took.

The three cafes and their order counts, from the PivotTable and `GROUP BY` of earlier lessons:

| store_name | city | orders |
|---|---|---:|
| Old Town | Oakland | 729 |
| Campus | Berkeley | 716 |
| Harbor | Alameda | 355 |

Three lines from three rows: the same action repeated. This lesson teaches how to hold several values together and repeat an action over them. By the end of this page Python will print the three lines.

<Aside type="note" title="You already know this">

**Match.** A list is a column of cells, and an index is a row number. A `for` loop is the fill-down of *Your first formulas* (E2): one rule, repeated for each item. A one-line comprehension is one formula over a whole range.

**Diverge.** A list counts from 0 where a spreadsheet counts rows from 1, and a slice leaves out its end (unit 1). A loop also repeats over a list of names and files, where a spreadsheet or a query handles all the rows of a table in one step; pandas brings that one-step way back in a later lesson.

</Aside>

### 1. Lists

**Idea.** A list holds values in square brackets, in order. Each value has a position, counted from 0, and `-1` is the last one. `list[a:b]` is a slice: it takes position `a` up to, but not including, position `b`, as it does for text.

**Try it:**

```python
prices = [3.00, 3.50, 4.50]  # Espresso, Americano, Latte
prices[0], prices[-1], prices[0:2]
```

**Predict:** what do the three expressions pick?

<details>
<summary>Reveal the result</summary>

```text
(3.0, 4.5, [3.0, 3.5])
```

</details>

*Why:* position 0 is the Espresso, `-1` counts from the end and finds the Latte, and `[0:2]` holds positions 0 and 1 only. A list can also grow: `append` adds an item at the end. After adding a Cold Brew at 4.75:

```python
prices.append(4.75)
prices
```

```text
[3.0, 3.5, 4.5, 4.75]
```

### 2. Loops over names

**Idea.** `for name in names:` runs the indented lines once for each item, with `name` set to that item. `zip` walks two lists together, so each pass gets one name and its count. Loops belong to names and files; a table of orders is not looped over row by row.

**Try it:**

```python
names = ["Old Town", "Campus", "Harbor"]
counts = [729, 716, 355]
for name, count in zip(names, counts):
    print(f"{name}: {count} orders")
```

**Predict:** what does it print?

<details>
<summary>Reveal the result</summary>

```text
Old Town: 729 orders
Campus: 716 orders
Harbor: 355 orders
```

</details>

*Why:* the loop ran three times, one for each pair, and each pass wrote one line. That answers the owner.

### 3. One-line comprehensions

**Idea.** A comprehension builds a new list from an old one in one line: the formula first, then `for` and the name. It is the loop that fills a list, written as a single formula over a range.

**Try it.** Double every price in the list of unit 1, as for two of each:

```python
[price * 2 for price in prices]
```

**Predict:** what does this one line give, for the list of unit 1 after the Cold Brew was added?

<details>
<summary>Reveal the result</summary>

```text
[6.0, 7.0, 9.0, 9.5]
```

</details>

*Why:* read it as "price times 2, for each price in prices". It is the work of this loop, written in four lines, and the answer is the same:

```python
doubled = []
for price in prices:
    doubled.append(price * 2)
doubled
```

```text
[6.0, 7.0, 9.0, 9.5]
```

Only this one-line form is taught here.

### 4. A tuple is a fixed record

**Idea.** A tuple is values in round brackets that cannot be changed after it is made. It is a fixed record, such as the pair of rows and columns of a table. You can unpack it into names.

**Try it:**

```python
orders.shape
```

**Predict:** `orders.shape` is the rows and columns of the table. What is it?

<details>
<summary>Reveal the result</summary>

```text
(1800, 6)
```

</details>

*Why:* 1,800 orders, and six columns: the `order_id`, `customer_id`, `store_id`, `ordered_at`, `status` and `payment_method` of the orders table. `rows, columns = orders.shape` unpacks it, and `rows` is then `1800`.

### 5. Check: trace a loop

Write down the three lines this loop prints, then run it. The picture above traced another list the same way.

```python
total = 0
for price in [3.00, 3.50, 4.50]:
    total = total + price
    print(price, total)
```

<details>
<summary>Reveal the result</summary>

```text
3.0 3.0
3.5 6.5
4.5 11.0
```

</details>

*Why:* each pass adds the price of that pass to the total so far, and prints both. The total after the last pass, 11.0, is the sum of the three prices.

<Aside type="tip" title="Remember">

- A list is ordered values in square brackets; positions start at 0 and a slice `[a:b]` leaves out `b`.
- `for item in items:` repeats the indented lines once for each item; `zip` pairs two lists.
- A comprehension is a loop that builds a list, in one line.
- A tuple, such as `orders.shape`, is a fixed record.
- Loop over names and files, not over the rows of a table.

**Common trap:** a slice with one item fewer than you wanted.

</Aside>
