## The question

The owner asks:

> Can the manager of each cafe open one chart, point at a bar, and read the exact sales and the number of orders of that cafe in that month?

The sales and the number of orders of each store and month, the first rows of the table behind the chart:

| store | month | amount | orders |
|---|---:|---:|---:|
| Old Town | 1 | 1,591.00 | 128 |
| Old Town | 2 | 1,162.00 | 103 |
| Campus | 1 | 1,518.75 | 114 |
| Campus | 2 | 1,508.25 | 115 |

By the end of this page you will build that chart, give each store its own fixed color, shape the label that appears when you point at a bar with a mouse (a computer is needed for that step), and save the chart as a file you can send. The charts on this page are pictures of what the notebook draws; in the notebook you can point at them.

### 1. px.bar returns a Figure

**Idea.** `px.bar(table, x="column", y="column", color="column", barmode="group")` takes a whole table and the names of its columns, as seaborn does, and returns a `Figure`: an object that holds the data and the layout. In a notebook `fig.show()` draws it; the renderers page says interactive renderers use the plotly.js library, with pan, zoom and hover, and the HTML export page adds that clicking a name in the legend hides its trace.

**Try it.** The sales of each store in each month:

```python
three = px.bar(store_month, x="month", y="amount", color="store", barmode="group")
print(type(three).__name__, len(three.data))
print([(t.name, len(t.y)) for t in three.data])
three.show()
```

### 2. Colors and order that you choose

**Idea.** Plotly Express chooses a color for each value of the `color` column, and an order for its traces and bars. `color_discrete_map={"value": "color"}` says the color of each value yourself, and `category_orders={"column": ["value", ...]}` says the order of the traces and the legend, of the bars of an x column and of the panels of a facet column.

**Try it.** The same chart, with and without Old Town:

```python
def colors_of(table):
    chart = px.bar(table, x="month", y="amount", color="store", barmode="group")
    return {t.name: t.marker.color for t in chart.data}


before = colors_of(store_month)
after = colors_of(store_month[store_month["store"] != "Old Town"])
print(before)
print(after)
print(before["Campus"] == after["Campus"])
```

**Predict:** Campus is the second store of the chart of three stores. Will it keep its color when Old Town is left out? Say True or False.

### 4. Save the chart

<Aside type="tip" title="Remember">

- `px.bar(table, ...)` returns a `Figure`: `data` holds the traces, one for each `color` value, and `layout` the rest. The notebook draws it with hover and zoom; this page shows pictures.
- Raw rows are drawn one rectangle each, and rectangles that share a category stack: a total, not a mean.
- `color_discrete_map` fixes the color of each value, `category_orders` the order of traces, bars and panels.
- `hover_data` adds columns and formats numbers, and `hovertemplate` rewrites the label.
- `write_html` saves an interactive file, large by default and small with `include_plotlyjs="cdn"`, which then needs the internet; `write_image` saves a still picture and needs Kaleido and Chrome.

**Common trap:** a color that Plotly Express picked for a store is not the store's color: draw two charts from two tables and the same store can change color.

</Aside>

<Aside type="note" title="Interactive or static?">

Interactive is worth it when readers have questions you cannot predict: an exact value, a month to zoom into, a store to hide by clicking its name in the legend, as the HTML export page lists. A page, a slide or a printout can only show the picture, so choose the chart, its order and its title as in *Charts that tell the truth* (E17) and *Charts with pandas and matplotlib* (P21); the later *Telling the story* (C15) goes deeper. Plotly Express can also step through a column of the table with `animation_frame`, as its animations page shows.

</Aside>

by_store = orders.assign(store=orders["store_id"].map(store_names),
