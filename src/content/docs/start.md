datafromzero is a free, open roadmap that starts where most people start, with spreadsheets. It goes
from Excel and Google Sheets to SQL, then Python, then an advanced core of statistics, Git, data
modeling and cloud basics, and finally the skills of four data careers. Every stage and every career branch is
published; lessons are still reviewed and improved, and the [changelog](/changelog/) lists each change.

Not an English reader yet? [Read in your language](/translate/) shows how to translate the pages with Chrome.

## Follow the order

Study the stages in this order:

1. **Excel / Sheets:** formulas, lookups and pivot tables.
2. **SQL:** ask questions of tables.
3. **Python:** pandas, notebooks and automation.
4. **Advanced core:** statistics, Git, data modeling and cloud basics.
5. **One career branch:** Data Analyst, Data Engineer, Data Scientist, or ML / AI Engineer.

You can skip a stage you already know. Excel / Sheets, SQL, Python and the advanced core each end their stage page with a
placement test: [Excel / Sheets](/excel/#placement-test), [SQL](/sql/#placement-test), [Python](/python/#placement-test)
and [Advanced core](/core/#placement-test). Excel, SQL and Python have two parts each. Answer without looking anything up. If every
answer is right, go on to the next stage; if not, the test tells you which lesson to start at, and it lists the lessons it does not
test. New to statistics? Skip the advanced core's test and start at its first lesson; that is normal.

## Two ways to read

- **Learn** is for studying in sequence. Each lesson is short, covers one idea at a time and has a
  fixed header: level, duration, when it was last reviewed, objectives and prerequisites.
- **Reference** is for looking things up later: a glossary, syntax for Excel, SQL and pandas,
  statistics formulas and career guides.

## Exercises, solutions and practice files

Try each exercise before you open its solution. Solutions are hidden directly under the exercise
and open with a click; this works without JavaScript.

Where you practice depends on the stage:

- **Excel:** each lesson has a practice workbook (`.xlsx`) to download. Open it in Excel, or upload
  it to Google Drive and open it with Google Sheets.
- **SQL:** you type and run queries in an editor on the lesson page. Nothing to install, no account,
  and nothing you type is sent anywhere.
- **Python:** each lesson links to a notebook. Use **Open in Colab** to run it in Google Colab (you sign in
  with a Google account; Colab is free of charge; paid plans exist, and you do not need them). Python lessons are written
  for a computer or tablet: on a phone you can read them, but running a notebook is hard.
- **Advanced core and the career branches:** each lesson says what it uses: the SQL editor on the page,
  a Colab notebook, or, for some, tools you install on your own computer.
- Practice datasets are in the project repository and are free to reuse (see the license page).

## Prerequisites and "Unlocks next"

Every lesson lists the lessons you should finish first under **Before this lesson**. The order of
lessons inside a stage always respects these links. At the bottom of each lesson, **Unlocks next**
lists the published lessons that build on it, so you can see where it leads.

## Your progress

datafromzero has no accounts. Your browser remembers the lesson you opened last, and when you open a lesson and come
back to this page or the home page you will see **Continue** with a link to it. Below, tick a lesson when you finish
it; each stage shows how many you have done. This is kept in this browser only: it is never sent anywhere, and it is
not shared between your devices. **Clear my progress** removes it (see [Privacy](/privacy/#progress)). If your browser
blocks storage, nothing is remembered; bookmark the lesson you are on, or note it down yourself.

Each stage also has a page with its lessons in order: [Excel / Sheets](/excel/), [SQL](/sql/), [Python](/python/),
[Advanced core](/core/), [Data Analyst](/data-analyst/), [Data Engineer](/data-engineer/),
[Data Scientist](/data-scientist/) and [ML / AI Engineer](/ml-engineer/).

## When you finish

Each career page ([Data Analyst](/data-analyst/#what-you-finish-with), [Data Engineer](/data-engineer/#what-you-finish-with),
[Data Scientist](/data-scientist/#what-you-finish-with) and [ML / AI Engineer](/ml-engineer/#what-you-finish-with)) has a
section, **What you finish with**: the hours for the whole route from the first Excel lesson, the capstone you hand in, and what
employers screen for. datafromzero gives no verified certificate, because it has no accounts. The [completion page](/completion/)
prints on one page for your own use, and says on it that it is not a certificate.

## Report a problem

Every lesson ends with a **Report an issue** form, and the **Report a problem** button (a small flag) in the menu at the
bottom of every page opens the same form: open the menu, tap the flag, write what is wrong or unclear and send it, no
account needed.

## The roadmap map

Four stages in order, then four career branches. Open a stage to see its lessons in the order to study
them. Each lesson has a short code to keep track of where you are: E1, E2 … for Excel, S for SQL, P for
Python, C for the advanced core, and DA, DE, DS and MLE for the branches. "Needs" lists the codes of the
lessons to finish first.
