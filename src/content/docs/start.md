datafromzero is a free, open roadmap for people who only know Microsoft Office. It goes from
Excel and Google Sheets to SQL, then Python, then an advanced core, and finally four data careers.
The site is still being written, so lessons appear stage by stage.

## Follow the order

Study the stages in this order:

1. **Excel / Sheets:** formulas, lookups and pivot tables.
2. **SQL:** ask questions of tables.
3. **Python:** pandas, notebooks and automation.
4. **Advanced core:** statistics, Git, data modeling and cloud basics.
5. **One career branch:** Data Analyst, Data Engineer, Data Scientist, or ML / AI Engineer.

You can skip a stage you already know. Read its last lessons first: if they feel easy, move on.

## Two ways to read

- **Learn** is for studying in sequence. Each lesson is short, covers one idea at a time and has a
  fixed header: level, duration, when it was last reviewed, objectives and prerequisites.
- **Reference** is for looking things up later: a glossary, syntax for Excel, SQL and pandas,
  statistics formulas and career guides.

## Exercises, solutions and practice files

Try each exercise before you open its solution. Solutions are hidden directly under the exercise
and open with a click; this works without JavaScript.

Practice happens outside this site, so nothing you type here is run or saved:

- Excel lessons link to a Google Sheets template. Use **Make a copy** to get your own.
- Python and SQL lessons link to a Google Colab notebook. Use **Open in Colab** and run the cells.
- Practice datasets are in the project repository and are free to reuse (see the license page).

## Prerequisites and "Unlocks next"

Every lesson lists the lessons you should finish first under **Before this lesson**. The order of
lessons inside a stage always respects these links. At the bottom of each lesson, **Unlocks next**
lists the published lessons that build on it, so you can see where it leads.

## Your progress

datafromzero has no accounts and does not save progress. Bookmark the lesson you are on, or note
it down yourself.

## Report a problem

Every lesson ends with **Suggest an edit** and **Report an issue** links. You can also open an issue in
the [project repository](https://github.com/datafromzero/datafromzero.github.io/issues). Small fixes
such as typos are welcome as pull requests.

## The roadmap map

Four stages in order, then four career branches. Open a stage to see its lessons in the order to study
them. Each lesson has a short code to keep track of where you are: E1, E2 … for Excel, S for SQL, P for
Python, C for the advanced core, and DA, DE, DS and ML for the branches. "Needs" lists the codes of the
lessons to finish first.
