datafromzero is written in English. If English is not your first language, Chrome can translate any page for you, and
this page shows how. It takes about a minute to set up.

## Translate, then reread in English

A translated page is a good way to understand a lesson. Reading in English is better in the long run, because SQL,
Python, spreadsheet functions, error messages and the documentation you will search all use English.

A practical mix:

1. Translate the page to understand the idea.
2. Switch back to English and reread the key terms and the headings.
3. When you meet an error message, search for it in English.

## On a computer

The steps below come from Chrome's help page for [computers](https://support.google.com/chrome/answer/173424?hl=en&co=GENIE.Platform%3DDesktop).

1. Open Chrome and go to the page you want to translate.
2. On the right of the address bar, select **Translate**.
3. Select your preferred language. If Translate does not work, refresh the page.

To pick the language Chrome translates into: select **More**, then **Settings**, then **Languages**. Under "Google
Translate", select **Translate into this language** and choose a language.

To translate English pages every time: go to **Settings**, then **Languages**. Under "Google Translate", next to
"Automatically translate these languages", select **Add languages**, choose **English**, then select **Add**. To stop,
select **Remove** next to English.

## On an Android phone or tablet

The steps below come from Chrome's help page for [Android](https://support.google.com/chrome/answer/173424?hl=en&co=GENIE.Platform%3DAndroid).

1. Open Chrome and go to the page.
2. In the notification at the top of the screen, tap the language you want to translate to.
3. If no Translate notification appears, tap **More**, then **Translate**.

To translate English pages every time: in the notification, tap **Settings**, then **Always translate pages in
English**. You can also tap **More**, then **Settings**, then **Languages**, then **Advanced**, then **Automatically
translate these languages**, then **Add language**, and choose English. To remove it later, tap **More**, then
**Remove** next to English.

To change the language Chrome translates into: **More**, **Settings**, **Languages**, **Advanced**, **Translate into
this language**.

## On an iPhone or iPad

The steps below come from Chrome's help page for [iPhone and iPad](https://support.google.com/chrome/answer/173424?hl=en&co=GENIE.Platform%3DiOS).

1. Open Chrome and go to the page.
2. At the top, select the language you want to translate to. Chrome translates the page that one time.
3. If you do not see Translate at the top, tap the **More** menu, then choose **Translate**. If it is still not there,
   refresh the page.

To translate English pages every time, the help page says: open **Settings**, then tap **Always translate English**.
It does not say more than that, so if the option is not where you expect it, open the help page above.

## What stays in English on purpose

On this site, code is marked so that translators leave it alone: code blocks, code inside a sentence, keyboard keys,
the SQL you edit and run on a page, and the column names in its results. SQL, formulas, function names and column
names must be spelled exactly, so that code you copy still runs. A translated `SELECT` is not a query.

The explanations around the code are prose, and Chrome can translate them.

## Privacy

Chrome's help pages for [computers](https://support.google.com/chrome/answer/173424?hl=en&co=GENIE.Platform%3DDesktop),
[Android](https://support.google.com/chrome/answer/173424?hl=en&co=GENIE.Platform%3DAndroid) and
[iPhone and iPad](https://support.google.com/chrome/answer/173424?hl=en&co=GENIE.Platform%3DiOS) do not say whether a page is
translated on your device or on Google's servers, so we do not say either. The Android page names the setting "Offer to
send pages in other languages to Google Translate". Read those pages and Google's own privacy information, then decide
whether you are comfortable translating a page.

You start the translation in Chrome. datafromzero does not take part in it and does not see what you translate. Our
own data practices are on the [privacy page](/privacy/).

## Other browsers

Other browsers have their own translators. Look in your browser's help for how it translates pages.
