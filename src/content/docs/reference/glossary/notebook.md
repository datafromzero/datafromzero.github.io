A notebook is a document that mixes code, plain-language text and results, so you can run a small piece, look at the answer and then go on. The Jupyter project describes it as a shareable document that combines computer code, plain language descriptions, data and visualizations. A text cell holds words, and a code cell holds Python. The notebook remembers what the cells you ran before did, so the order you run them in matters. The Python lessons open their notebooks in [Google Colab](/reference/glossary/colab/).
