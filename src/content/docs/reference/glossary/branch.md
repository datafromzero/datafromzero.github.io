A branch is a line of development in Git. Your new commits go onto the branch you are on, and the main line, called `main`, stays as it was. You use a branch to try a change safely, then ask for it to be merged back, usually through a pull request that a teammate reviews. The Git glossary describes a branch as a line of development whose most recent commit is its tip. In the lessons a branch is a label on a [commit](/reference/glossary/commit-git/), and a new commit moves only the branch you are on.
