PII is information that can identify a person. The NIST guide defines it as any information that can be used to distinguish or trace an individual's identity, and any other information that is linked or linkable to an individual. Removing the name is not enough: an id that stands in for a name, a pseudonym, still ties all of a person's records together, and a few ordinary fields can single a person out. Treat a table with ids as personal data, even if it has no names.
