An argument is a value that you pass to a function when you call it. The Python documentation distinguishes two kinds: a keyword argument is preceded by its name (`ndigits=1`), and a positional argument is any other, read by its place. Spreadsheet functions have arguments too: the range in `SUM(F2:F8)` is its argument. A function's signature lists the arguments it accepts.
