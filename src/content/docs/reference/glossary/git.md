Git is a tool that keeps the history of a project's files. You save a version with a [commit](/reference/glossary/commit-git/), work on a separate line with a [branch](/reference/glossary/branch/) and keep the whole history in a [repository](/reference/glossary/repository/). The Git website says it is released under the GNU General Public License version 2.0, an open source license. Git and GitHub are not the same thing: GitHub is a website that hosts Git projects.
