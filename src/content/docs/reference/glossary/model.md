A model is a rule that a computer learns from data and then uses to make predictions on new rows. Google's machine learning course defines it as a mathematical relationship derived from data that a machine learning system uses to make predictions. You give the model the [features](/reference/glossary/feature/) of a row, and it returns a guess about the target, such as a chance between 0 and 1. A model is worth trusting only if it beats a simple [baseline](/reference/glossary/baseline/) on rows it has not seen. In the database lessons, a data model is something else: a plan of tables.
