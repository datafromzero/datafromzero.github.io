In Git, a commit is a saved snapshot of the files you chose, with your name, a date and a message that says what changed and why. The history of a project is a chain of commits, and you can go back to any of them. You save one in two steps: `git add` chooses the files, and `git commit -m "message"` saves them. The Git glossary describes a commit as a single point in the Git history. The word means something else in a database: see [Commit (database)](/reference/glossary/commit-database/).
