A KPI is a key number that shows how things are going against a goal. Microsoft Learn describes a KPI as a visual cue that communicates the amount of progress made toward a measurable goal. In these lessons a KPI is a number someone would act on, such as total sales, the number of orders or the average order, shown with the formula it comes from. Pick KPIs from the decision a screen supports, not because they are easy to compute.

## Where you meet it

- [*A one-screen report you can hand over*](/excel/one-screen-report/) (E21): three KPI cells built from formulas, never typed numbers.
- [*Designing a dashboard people will use*](/data-analyst/dashboard-design/) (DA8a): choose KPIs from the decision.
