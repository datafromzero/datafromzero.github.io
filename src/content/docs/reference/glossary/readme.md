A README is the first file to read in a project or a dataset. GitHub describes it as the place to tell other people why your project is useful, what they can do with it and how they can use it. In this course a dataset's README lists its tables, columns and row counts and its known quirks: the cafe-sales README says, for example, that order 2075 has a quantity of 20 where 2 was meant. When you build a project of your own, write its README for a stranger who has never seen it.

## Where you meet it
