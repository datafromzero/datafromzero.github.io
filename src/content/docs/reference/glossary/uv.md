uv is a Python package and project manager, written in Rust and backed by Astral. Its documentation says it can replace tools such as `pip` and `virtualenv`. In the lessons it does three jobs: it installs Python, it builds a project's [environment](/reference/glossary/virtual-environment/) from the files the project declares, and `uv run` runs a script inside that environment.
