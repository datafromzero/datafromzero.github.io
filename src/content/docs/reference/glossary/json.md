JSON is a plain-text format for data that is easy for people to read and write. It has two building blocks: a collection of name and value pairs, and an ordered list of values. An order written in JSON can hold its own list of lines, which one row of a table cannot, so reading JSON into a table often starts with flattening it. Web APIs usually answer in JSON.
