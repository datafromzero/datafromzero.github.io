An API (application programming interface) is a set of features and rules that lets other software use a program, instead of a person using its screen. MDN calls it a contract between the program that offers it and the software that uses it. A web API answers a request sent to an address with a status code and data, usually [JSON](/reference/glossary/json/). In the Data Engineer lessons the cafe's tills sit behind an API, and a pipeline asks it for the orders.
