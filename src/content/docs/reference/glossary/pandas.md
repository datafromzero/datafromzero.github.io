pandas is a Python package for working with tables; the Python lessons use it for every table. Its documentation says it provides data structures designed to make working with relational or labeled data both easy and intuitive, and that it is built on NumPy. A table in pandas is a [DataFrame](/reference/glossary/dataframe/). Most pandas steps have an Excel or SQL twin: `groupby` is `GROUP BY`, and `merge` is a join.
