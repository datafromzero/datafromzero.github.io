A baseline is the reference result that a new number or model has to beat. Google's machine learning glossary defines it as a model used as a reference point for comparing how well another model is performing. A baseline can be very simple: give every customer the share of customers who left, or guess the usual value for every order. A model that does not beat its baseline adds nothing. In a spreadsheet a baseline can also be the starting numbers, before any filter, that you compare later results with.
