A terminal is a text window where you type commands instead of clicking. MDN describes it as a text interface for executing text-based programs. The words terminal, shell and command line are often used as if they meant one thing; technically, a terminal is the software that starts a shell, and the shell is the session where your commands run. You use the terminal to move between folders, run a script and use tools such as [Git](/reference/glossary/git/). The Data Engineer track needs one.
