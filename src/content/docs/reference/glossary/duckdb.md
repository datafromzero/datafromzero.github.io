DuckDB is a free, open source database engine built for analysis: it answers SQL queries over tables of data. It runs inside the program that uses it instead of as a separate server, so there is no database software to install, update or look after. The DuckDB site says it is released under the MIT License. The SQL lessons run their queries in DuckDB, and later lessons use it from Python too.
