A repository, or repo, is a project folder together with the history of its files. Git keeps that history in a hidden `.git` folder inside the project. Websites such as GitHub host repositories, so that a team can share one. The Git glossary defines the term more exactly, as a collection of references together with an object database that holds the history. A repository holds the [commits](/reference/glossary/commit-git/) and [branches](/reference/glossary/branch/) of one project.
